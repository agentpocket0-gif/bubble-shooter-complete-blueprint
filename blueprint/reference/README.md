# reference/ — generated, not written by hand

This folder is filled by `.github/workflows/rea_extract.yml`. It is empty until you add your own package and
run the workflow once.

The workflow writes here:

- `01_LOADING_SCREEN_UI_AND_ANIMATIONS.md`
- `02_BUBBLES_BOOSTERS_AND_LEVELS_SYSTEM.md`
- `03_STORE_IAP_AND_MONETIZATION_ADS.md`
- `04_COMPLETE_ASSETS_CATALOG.md`
- `05_MASTER_AI_GAME_BUILDER_PROMPT.md`
- `assets_inventory.csv` (every file, size and image dimension)
- `_extraction_report.json` (machine-readable counts)

Do not edit these by hand — the next run overwrites them. If you need a change, change
`scripts/analyze_apk.py` and re-run.
