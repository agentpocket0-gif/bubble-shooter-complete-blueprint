## 2. Game project

The original Godot game lives under godot_project/:
- project.godot, export_presets.cfg
- scenes/ and scripts/
- autoload/GameState.gd and AssetRegistry.gd
- tests/
- assets/own/ is generated by tools/generate_original_assets.py
- levels/ is generated by tools/generate_levels.py

Do not treat the old android/ app as the game. It is a separate APK analysis utility.

## 3. Third-party reference material

The folder godot_project/assets/real_pack/ contains 1,595 files extracted from another publisher's app. Its REAL_PACK_MANIFEST.json explicitly marks it NOT cleared for publication. Do not copy it into the game, AssetRegistry, screenshots, Android exports, or releases.

The reference code/data folders and the blueprint may be used to understand general mechanics and documented dimensions. Do not copy protected source code, original artwork, recorded audio, fonts, logos, exact level layouts, app name, or trademarks.

## 4. Six-department pipeline

- tools/rea_analyzer.py: documented reference audit.
- tools/generate_original_assets.py and tools/asset_audit.py: original game art and rights checks.
- tools/generate_levels.py and tools/validate_levels.py: 120 original levels and schema validation.
- tools/llm_router.py and tools/autonomous_studio_orchestrator.py: rate-limited model discovery and restricted self-healing.
- tools/run_validation.sh and tools/run_visual_qa.sh: headless and screenshot checks.
- tools/replica_vision_qa.py: OpenCV state/blank-frame validation and optional multimodal review.
- .github/workflows/autonomous_6dept_studio.yml: CI, Android export, QA commit and release.

## 5. Release status

This is an initial playable foundation, not a store-verified production release. See docs/BUILD_STATUS.md for what remains. The Android pipeline requires a persistent user-owned upload keystore in GitHub Secrets before it can create the signed AAB.
