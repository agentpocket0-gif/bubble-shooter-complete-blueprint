# Asset credits

The in-game artwork is generated by tools/generate_original_assets.py and authored as original SVG vector art for Bubble Shooter: Classic Blast in this repository. No extracted publisher artwork, sound recording, font, level layout, logo, icon, or source code is included in the runtime game assets.

The folder godot_project/assets/real_pack/ is explicitly marked publishable=false in its own manifest. It is excluded from AssetRegistry, the game scripts, and all Android exports. Do not copy its contents into the game.

No audio files are currently bundled. Add original or commercially licensed audio only after recording its creator, source, license, attribution terms, and redistribution rights here.
