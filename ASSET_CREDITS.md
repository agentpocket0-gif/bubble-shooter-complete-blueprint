# Asset credits and provenance

Every file under `godot_project/assets/` was generated by
`scripts/generate_original_assets.py` in this repository, from the specifications
in `blueprint/original/06_AUDIO_AND_SOUND_DESIGN.md` and
`blueprint/original/07_ASSET_PRODUCTION_SPEC.md`.

- 142 sprites (bubbles, blockers, boosters, cannon, HUD icons, map nodes, UI
  frames, FX) drawn procedurally with Pillow and numpy.
- 46 audio files (3 music beds, 43 SFX) synthesised procedurally.
- No third-party artwork, audio, font, icon or level data is included, and
  nothing is derived from another game's files.

You own the output. No attribution is required. Keep this file with the project:
if a store reviewer or a rights-holder ever asks where the art came from, this is
the answer.

## Level data

`godot_project/levels/*.json` is generated by `tools/levelgen.py`, which is part
of this repository. Each level records the greedy solver's result
(`shots_used`, `score`) so the balance claim is auditable rather than asserted.

## Fonts

The project uses Godot's built-in default font, which is licensed under the SIL
Open Font License and ships with the engine. No font file is bundled here.
