# Bubble Shooter: Classic Blast - build instructions

## Repository correction and implementation scope (9 November 2026)

This file supersedes any earlier instruction that described the extracted art pack as copyright-free or safe to redistribute. The manifest at godot_project/assets/real_pack/REAL_PACK_MANIFEST.json explicitly says publishable=false. Those files are for private study only and must not be shipped in the game, a screenshot pack, an APK, an AAB, or a GitHub release.

Build an original Godot mobile bubble shooter under package ID com.classicblast.bubbleshooter. Use the documented mechanics and general measurements as design references, not as permission to reproduce a commercial game's protected art, audio, fonts, code, exact level layouts, logos, name, or trademarks.

## Project layout

- godot_project/project.godot: Godot game project.
- godot_project/scenes/: Splash, SagaMap and Gameplay.
- godot_project/scripts/: HexGrid and gameplay/UI behaviour.
- godot_project/autoload/: save state and original asset registry.
- godot_project/assets/own/: original SVG art generated by tools/generate_original_assets.py.
- godot_project/levels/: 120 original JSON levels generated by tools/generate_levels.py.
- config/live_monetization_config.json: ads and IAP disabled by default.
- tools/: six-department audit, generators, validators, router, self-heal, and QA.
- .github/workflows/autonomous_6dept_studio.yml: CI and Android export.

## Requirements

1. Use an odd-row staggered hex grid, row pitch d * sqrt(3) / 2, six neighbours, BFS matching, and flood-fill from the top row.
2. Include map, gameplay, result, and simple settings/booster UI.
3. Generate 120 original levels. Validator output is structural, not a guarantee of perfect solvability or balancing.
4. Keep ads and IAP disabled until SDK, consent, privacy, and store-policy work is complete.
5. Never draw the production bubbles/buttons with draw_circle() or synthesize beep audio through AudioStreamGenerator. Use the original SVG artwork under assets/own/; add only original or appropriately licensed audio.
6. Run headless tests, Xvfb screenshots, OpenCV checks, and optional multimodal visual inspection.
7. Read secrets from GitHub Actions only. Do not commit keys or keystore files.
8. The AAB must be signed with the same persistent upload key used for future Play releases.

## Current Android settings

Google Play requires new Android mobile apps to target API 36 from 31 August 2026. The Android export presets use API 36, Godot 4.7.2 stable, Java 17 and the Android SDK/NDK from the workflow.

## Completion boundary

The current implementation is an initial playable foundation with automated smoke tests. It must not be described as production-ready until the workflow passes, a human plays it on real devices, the gameplay and blockers are completed, and store policy/legal checks are finished.
